# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

投递的印张名必须命中前缀白名单：以白名单中任一条目开头才入队，否则当场退回。白名单由印刷员（writer）维护，增删均写入变更履历；前缀删除只影响此后的新投递，已经入队的旧任务保留原名继续处理。只读账号（reader）可查看白名单、当日退回样例与变更履历，但不能改动。

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 白名单初始只保留“封面”：投“封面-01”类印张应收下，投“内页-09”应被退回（页面提示退回，顶栏“前缀白名单”页的“当日退回样例”可见该次退回）。
3. 顶栏进入“前缀白名单”页：含维护区、当日退回样例、变更履历三块；新增“内页”前缀后履历出现一条新增记录，再投内页印张可以入队。
4. 删除“封面”前缀后再投“封面-xx”应退回；队中旧的封面任务仍保留原名并正常出结论，履历出现一条删除记录。
5. checker 登录后看不到任何维护/投递入口；可进入白名单页查看白名单、当日退回样例与履历，但新增、删除、投递接口一律 403。
