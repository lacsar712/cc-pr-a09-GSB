# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

投递名必须命中**前缀白名单**：印刷员维护合法前缀，投递名不以任一前缀开头就当场退回；前缀的增删写入变更履历。已经入队的旧任务不受事后删前缀影响。只读账号能看白名单、当日退回样例与变更履历，但不能改。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可维护前缀白名单 |
| checker | check123456 | 只看 |

## 启动

```bash
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准；内页-09 是白名单建立前入队的旧任务，仍按原名处理。
2. 顶栏进入「前缀白名单」页：白名单初始只保留「封面」，可见维护区、当日退回样例、变更履历（含系统建立的「新增 封面」）。
3. 回复核台投一条「封面-01」（青 0.08 / 品 0.02），状态先待处理随后变套准。
4. 投一条「内页-09」，接口 422 退回并提示未命中前缀；白名单页「当日退回样例」出现该条。
5. 在白名单页删掉「封面」，履历新增一条「删除 封面」；再投「封面」任意名仍被退回，而旧的封面任务保留原名不变。
6. 新增一个前缀（如「插页」），履历新增「新增」；随后「插页」开头的投递可入队。
7. checker 登录：复核台无送复核按钮，白名单页无新增/删除控件，只能查看。

## 接口

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/prefixes` | 白名单 | 登录即可 |
| POST | `/api/prefixes` | 新增前缀，写履历 | 印刷员 |
| DELETE | `/api/prefixes/{前缀}` | 删除前缀，写履历 | 印刷员 |
| GET | `/api/prefixes/audit` | 变更履历 | 登录即可 |
| GET | `/api/rejections/today` | 当日退回样例 | 登录即可 |
| POST | `/api/jobs` | 送复核；未命中前缀记退回并返回 422 | 印刷员 |
